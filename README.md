# Veterinary Clinic — Pet Care App

> Interactive web app prototype for veterinary clinics, featuring service booking, pet health tracking and a digital vaccination card.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Veterinary care & pet services

Interactive web app prototype for veterinary clinics, featuring service booking, pet health tracking and a digital vaccination card.

**Highlights**

- Pet health timeline with visits and grooming history
- Digital vaccination card with booster reminders
- Subscription-based care plan

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
